# 🇪🇸 西班牙语学习应用

一款专为A1-A2水平初学者设计的西班牙语学习应用

## ✨ 核心功能

- 📚 **150篇精心编排的短文**
- 🎤 **高质量发音集成**（Edge TTS神经网络发音）
- 🔄 **遗忘曲线复习系统**
- 📊 **智能学习进度追踪**
- 🌐 **9种西班牙语方言**
- 🎯 **音标和音节划分辅助学习**

## 🚀 一键启动

### Windows
```bash
# 方式1：双击运行
start.bat

# 方式2：命令行
npm start
```

### Mac/Linux
```bash
chmod +x start.sh
./start.sh
```

### Edge TTS集成
- ✅ 自动启动发音服务

- ✅ 支持语速调节

## 🛠️ 技术栈

- **前端**: React 18 + TypeScript
- **框架**: Ionic Framework
- **发音**: Edge TTS神经网络
- **构建**: Vite
- **存储**: LocalStorage

## 🎓 学习方法

### 每日学习建议
1. 听发音建立语感（-30%语速）
2. 查看音标学习发音规则
3. 使用音节划分理解节奏
4. 跟读模仿发音
5. 完成复习任务
6. 记录学习进度

### 学习时间
- 建议每日15-30分钟
- 复习旧知识
- 学习新内容
- 周末回顾总结

## 🔧 开发

### 依赖
- Node.js 14+
- Python 3.8+ (发音服务)
- pip install edge-tts

### 启动开发模式
```bash
# 启动应用
npm run dev

# 启动发音服务（另一个终端）
cd server
node server.js
```

### 构建生产版本
```bash
npm run build
```

## ⚠️ 常见问题

### Q: 发音服务启动失败？
A: 运行 pip install edge-tts

### Q: 端口被占用？
A: 修改server/server.js中的PORT

### Q: 需要网络？
A: 发音服务需要网络，应用本身可离线学习
